# Khelzaar Games — site hosting

Temporary GitHub Pages host for all 10 games' store listing pages (privacy
policy, terms, mini landing page) while real domains (see each game's repo
README) are set up. Served at https://maazforteve.github.io/khelzaar-sites/

Each game's own source is in its own private repo (`khelzaar-<slug>`); this
repo holds only the static `store/site/` output, copied from there.
